計算口徑說明：
1. 整付保費：現金流為 t₀ 流出整付保費 P，第 N 年末流入保單價值 SV，其餘年度為 0。IRR 即滿足 −P + SV∕(1+IRR)N = 0 的折現率（亦等於 (SV∕P)1∕N − 1）。
2. 年繳保費：於每年初（t = 0…繳費年期−1）流出年繳保費 A，第 N 年末流入保單價值 SV。IRR 由整組現金流 −A, −A, …, +SV 求解。
3. 累計已繳保費：整付 = P；年繳 = A × 繳費年期。
4. 淨收益 = 總領回 − 累計已繳保費；絕對回報率 =（總領回 − 已繳保費）÷ 已繳保費，以 % 顯示（非年化）。
5. IRR 採二分法求解淨現值（NPV）= 0，區間 −99% 至 +500%；深度虧損（保單價值低於總繳保費過多）可能無正解，顯示「—」。
6. 定期提取：啟用後，於「提取開始年度」至「提取結束年度」每年領出「每年提取金額」，作為現金流流入併入 IRR；總領回 = 累計提取 + 保單價值，絕對回報率 =（總領回 − 已繳保費）÷ 已繳保費。提取年度自動限制在 [1, 結算年度] 內且 開始 ≤ 結束；設「每年提取金額 = 0」或取消勾選即等同不提取。
7. 本工具為純數值回報測算，未計入費用、稅務、通脹及非保證紅利波動，不構成投資建議。
