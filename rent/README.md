# 退租水电燃气费用结算计算器（深圳住宅）

在线使用：**https://hkcyclops.github.io/rent/**

根据租客退租时的走表读数，计算应付未付的水费、电费、燃气费。适用于**深圳住宅**（一户一表 / 合表），不适用于工业及城中村转供加价场景。

## 功能

- 输入「上次抄表日 + 退租走表读数」→ 自动计算本周期费用与应付未付金额
- **阶梯按自然月分段**：抄表周期跨月时，按各月天数分摊用量并逐月套用阶梯，跨夏/冬季自动切换费率
- 支持一户一表（阶梯）与合表用户（单一价）切换
- 一户多人口档位基数调整（水 +5m³/人、电 +100kWh/人、燃气 +6m³/人，需向经营企业申请）
- 每项可填「周期内已结金额」自动抵扣，输出明细算式与合计
- 费率可自行修改，一键恢复官方默认
- 可打印 / 导出 PDF 结算单（含双方签字栏）

## 费率口径（深圳官方）

| 项目 | 费率 | 季节调整 |
|---|---|---|
| 水（含污水处理费） | 一档 3.67、二档 6.04、三档 12.35 元/m³ | 按月度阶梯 0–22–30 m³，无季节差异 |
| 电 | 一档 0.6542、二档 0.7042、三档 0.9542 元/kWh | 夏季（5–10月）档位 0–260–600；非夏季 0–200–400 |
| 管道燃气 | 3.41 / 3.91 / 5.16 元/m³ | 夏季一档 0–30 m³；冬季（11–4月）一档 0–40 m³ |

补充口径：

- 水价：深发改〔2025〕354号，自 2025 年 7 月 1 日起实施；污水处理费按深发改〔2022〕610号（自来水价 2.67/4.54/9.35 + 污水 1.00/1.50/3.00）。合表用户 3.57+1.18=4.75 元/m³，不执行阶梯。
- 电价：《深圳市居民生活电价价目表》，一户一表阶梯电度电价（含税），未含少量政府性基金及附加，如需精确可自行微调单价；合表电价 0.6999 元/kWh。
- 燃气价：深发改〔2022〕607号（管道天然气，瓶装气不适用）。未实行阶梯的合表居民一般按一档价执行。
- 阶梯水量/电量/气量按月计量，月间不累计、不结转。

## 计算口径说明

用量按抄表周期内覆盖的自然月天数分摊，逐月套用该月的阶梯与季节费率，为合理估算口径；若与供水 / 供电 / 燃气企业实际账单存在差异，以账单为准。
