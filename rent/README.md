# 退租水电燃气费用结算计算器（深圳住宅）

在线使用：**https://hkcyclops.github.io/rent/**

根据租客退租时的走表读数，计算应付未付的水费、电费、燃气费。适用于**深圳住宅**（一户一表 / 合表），不适用于工业及城中村转供加价场景。

## 功能

- 输入「上次抄表日 + 退租走表读数」→ 自动计算本周期费用与应付未付金额
- **阶梯按自然月分段**：抄表周期跨月时，按各月天数分摊用量并逐月套用阶梯，跨夏/冬季自动切换费率
- 支持一户一表（阶梯）与合表用户（单一价）切换
- 一户多人口档位基数调整（水 +5m³/人、电 +100kWh/人、燃气 +6m³/人，需向经营企业申请）
- 每项可填「周期内已结金额」自动抵扣，输出明细算式与合计
- 费率可自行修改，一键恢复官方默认
- 可打印 / 导出 PDF 结算单（含双方签字栏）

## 费率口径（深圳官方，均为「到户实收价」，含各项政府性基金及附加）

| 项目 | 费率 | 季节调整 |
|---|---|---|
| 水（自来水+污水处理费+垃圾处理费） | 一档 4.201、二档 6.571、三档 12.881 元/m³ | 按月度阶梯 0–22–30 m³，无季节差异 |
| 电（电度电价+政府性基金及附加） | 一档 0.6629、二档 0.7129、三档 0.9629 元/kWh | 夏季（5–10月）档位 0–260–600；非夏季 0–200–400 |
| 管道燃气 | 3.41 / 3.91 / 5.16 元/m³ | 夏季一档 0–30 m³；冬季（11–4月）一档 0–40 m³ |

**水费构成**（深发改〔2025〕354号 + 深发改〔2022〕610号 + 深发改〔2017〕1063号）：

- 自来水价：2.67 / 4.54 / 9.35 元/m³（2025 年 7 月 1 日起）
- 污水处理费：1.00 / 1.50 / 3.00 元/m³
- 生活垃圾处理费：0.59 元/m³，按「排污水量折算系数法」计收，一般客户**按用水量的 90% 折算污水量**，故到户实际为 **0.531 元/m³**（该项在工具明细中单独拆行列示）
- 合表水价：3.57 + 1.18 + 0.531 = 5.281 元/m³，不执行阶梯

**电费构成**（《深圳市居民生活电价价目表》，含税）：

- 电度电价：0.6542 / 0.7042 / 0.9542 元/kWh
- 政府性基金及附加：0.00866875 元/kWh（国家重大水利工程建设基金 0.196875 + 大中型水库移民后期扶持基金 0.62 + 小型水库移民后期扶持基金 0.05，单位：分/kWh）
- 到户总价：**0.6629 / 0.7129 / 0.9629 元/kWh**（与深圳供电局公开答复的 0.66286875 / 0.71286875 / 0.96286875 一致）
- 合表电价：0.6912 + 0.00866875 = **0.6999 元/kWh**（深圳供电局对外口径 0.69986875）

**燃气**（深发改〔2022〕607号，管道天然气，瓶装气不适用）：3.41 / 3.91 / 5.16 元/m³；未实行阶梯的合表居民一般按一档价执行。

阶梯水量/电量/气量按月计量，月间不累计、不结转。

## 计算口径说明

用量按抄表周期内覆盖的自然月天数分摊，逐月套用该月的阶梯与季节费率，为合理估算口径；若与供水 / 供电 / 燃气企业实际账单存在差异，以账单为准。
